### 문제 설명

<p>원하는 년 월 일을 입력받아 해당 년 월의 달력과 해당일의 요일을 출력하는 프로그램을 작성하시오.</p>
<p>&nbsp;</p>
<p>※ 윤년과 평년을 구별하는 방법은 다음과 같다.</p>
<p>1) 400의 배수는 모두 윤년이다.</p>
<p>2) 4의 배수이며 100의 배수가 아니면 윤년이다.</p>
<p>3) 나머지는 모두 평년이다.</p>
<p>&nbsp;</p>
<p>※ 요일은 영어로 아래와 같다.</p>
<p>일요일 Sunday</p>
<p>월요일 Monday</p>
<p>화요일 Tuesday</p>
<p>수요일 Wednesday</p>
<p>목요일 Thursday</p>
<p>금요일 Friday</p>
<p>토요일 Saturday​</p>

### 입력 

<p>해당하는 년 y(y 는 2,000 이상 2,010 이하의 정수) 월 m( m은 1부터 12사이의 정수) 일 d( d는 해당 월 사이의 수)을 공백으로 구분하여 입력받는다.</p>

<p>하나의 결과가 출력되면 프로그램을 종료한다.</p>

<p>데이터의 크기가 주어진 범위를 벗어날 경우는 "INPUT ERROR!"를 출력하고 다시 입력받는다.</p>

### 출력 

<p>해당 년 월의 달력을 출력하고 해당 날짜의 요일을 출력한다.</p>

<p>달력의 가장 왼쪽은 일요일이다. 요일은 공백으로 구분하여 출력한다.</p>

<p>날짜는 아래 출력 예와 같이 자리수를 맞추어 출력해야 한다.(요일과 요일사이 공백 날짜는 요일의 마지막글자에 맞춘다.)</p>

<p>날짜를 계산할 때에는 윤년도 고려하여야 한다. 2000년 1월 1일은 토요일이다.</p>

### 예제 입력

<pre>2000 2 30  
2000 10 22</pre>
